AI EMPOWERED / AI 赋能实践

让 AI 放大产品判断，
而不是替代它。

从市场研究、产品定义到样品评审与项目协作，AI 负责适合机器处理的信息工作；产品边界、取舍与最终结论始终由人确认。

Nextly 2.0 ↗ 将 AI 分析、Human Gate 与状态同步嵌入五阶段产品开发 Workflow，是这套方法的一次完整产品化实践。

CORE VALUE / 四个核心价值

AI 在哪些环节最有价值？

01

前期调研与需求洞察

输入：竞品数据 / 评论 / 运营反馈

AI：聚类、结构化、补充分析维度

人工：判断哪些信号真正具有产品意义

输出：机会方向 / 调研结论 / PRD 输入

外部数据整理痛点归集PRD 产出维度拓展收束
02

结构化信息处理

需要结构化的信息——表格汇总、框架搭建、BOM 归集、报价表整理。AI 按固定格式输出初稿，人为校验修正，后续维护也更便捷。

表格汇总框架搭建BOM 归集维护便捷
03

AI 辅助造型设计

输入：产品需求 / CMF 方向 / 结构限制

AI：快速生成多个视觉候选方向

人工：筛选、修正，并结合制造和产品约束判断

输出：可以进入工业设计讨论的概念方向

概念图生成多工具协作造型拆解CMF 方案
04

知识库与经验沉淀

将长期业务经验和项目边界变成 AI 可以持续调用的上下文，减少长对话中的遗忘和方向漂移。把工艺知识、供应商信息、产品判断原则、CMF 规则、项目上下文和输出规范沉淀为可复用 Skill——不确定时即时查询，比如"拐杖表面工艺有哪些，分别对应哪个供应商，交期预估，过往样品"。

Skill 沉淀即时查询工艺匹配供应商关联

FROM PERSONAL USE TO TEAM WORKFLOW

从个人使用，到团队可复用流程。

主导将AI引入产品研究与项目协作，把分散的市场数据、竞品信息、用户评论和开发资料，整理为具有固定输入、输出和人工复核边界的工作流，并沉淀为团队可复用的模板、Skill与知识库。

01 / INPUT

标准化输入

市场数据、竞品信息、Review/VOC、CMF/BOM及开发资料

02 / OUTPUT

固定输出

市场调研、竞品分析、产品Brief、项目复盘

03 / REVIEW

人工复核

AI负责数据处理、检索、聚类和初步分析；关键结论由人工复核并用于产品决策

04 / KNOWLEDGE

团队沉淀

将分析框架、输出规范、项目原则和工艺知识沉淀为模板、Skill及结构化知识库

六阶段新品开发SOP覆盖40+在研项目7大品类项目看板

以上为产品开发机制与项目管理范围，不代表40+项目由AI自动管理。

FROM FRAMEWORK TO EVIDENCE / 从框架到项目证据

以精品拐杖为例，AI 只接手可复核的处理工作。

这条链路把通用方法落到一个真实项目：外部数据由专业工具获取，AI 负责清洗、聚类与初步归纳，人把结论转化为产品要求并组织样品评审。

01 / INPUT

外部数据输入

市场数据、竞品信息、用户评论与现有产品反馈。

→
02 / AI PROCESS

清洗与聚类

AI 结构化信息、归纳问题并辅助检索，不直接给出产品结论。

→
03 / HUMAN DECISION

形成产品要求

人工复核证据，综合体验、结构、工艺、成本与市场匹配度。

→
04 / DELIVERY

方案与样品评审

首轮 6 种方案进入评审，筛选 5 种继续验证。

边界：AI 参与数据处理与概念探索；项目负责人组织阶段评审并承担最终判断。
