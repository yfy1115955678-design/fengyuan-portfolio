01 / PROBLEM

从医学影像，到可计算的功能学信息。

冠状动脉造影能够呈现血管狭窄等形态信息，但单纯依赖影像形态难以直接量化供血功能。本项目尝试将临床 CAG 影像与计算力学结合，通过数值模拟获得血流速度、压力及壁面剪切应力等信息，为冠脉狭窄的功能学分析提供新的计算路径。

核心问题：如何从二维临床影像出发，建立可信的三维血管计算模型，并证明计算结果与真实血流具有足够的一致性？

CAG 影像→血管结构提取→数值计算→血流动力学信息

02 / METHOD

从二维影像建立可计算的三维血管。

从 CAG 造影序列中选择病变暴露清晰、造影液充分充盈的关键帧，通过 Frangi 滤波增强血管结构，再完成血管轮廓提取、几何修复与三维重建，为后续血流动力学计算建立几何基础。

01

Frame Selection

选择狭窄部位暴露清晰、造影液充分充盈的关键帧。

02

Image Processing

基于 Hessian 矩阵的 Frangi 滤波，增强血管结构、抑制背景干扰。

03

Geometry Extraction

在 Mimics 中提取血管外轮廓，在 SolidWorks 中进行几何修复与中心线处理。

04

3D Reconstruction

建立可用于流体域与固体域计算的三维血管几何模型。

03 / MODEL

让模型尽可能接近真实生理状态。

将血液与血管壁分别建立为流体域和固体域，并通过 FSI 界面进行双向耦合。模型引入非牛顿血液特性、血管壁超弹性材料模型以及患者实际压力数据，使计算条件尽可能贴近真实生理环境。
