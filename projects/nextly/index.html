Nextly

新品调研与 Brief 生成工作台

把日常新品调研中的数据获取、清洗、分析、机会识别和 Brief 输出，整理成适合小团队快速判断、能够复盘的工作流。

核心结果
约 1 周流程缩短至 1–2 天
01 / PROBLEM

人手有限时，重复整理正在挤压真正的判断。

小团队需要快速周转新品，但市场调研、竞品分析和产品 Brief 主要依靠人工完成。大量时间消耗在不同工具、数据格式、表格、AI 对话和阶段产物之间反复切换与重复整理。

BEFORE / 原人工工作流：影刀抓取商品数据 → 卖家精灵批量下载评论 → AI 分析数据并汇总表格 → 人工筛选、判断并总结用户痛点 → 再次整理成结构化表格 → 编写 PRD → 头脑风暴 → 修改方案 → 评审。

我的目标不是让 AI 自动决定做什么，而是把原本散落在多个工具、表格和 AI 对话中的产品前期判断流程，收束进一个具有固定输入输出、能够追溯和复盘的工作环境。

02 / WORKFLOW

把一次性经验，变成可复用的分析流程。

AFTER / 进入 Nextly 后的工作流：数据上传 → 结构化分析 → 评论 / 痛点分析 → 机会识别 → 产品方向 → PRD / Brief → 头脑风暴与方案迭代 → 质量审查 → 评审准备 → 决策记录。数据抓取目前仍需外部工具（影刀 / 卖家精灵 / AI 辅助获取），这一点不假装自动化。

输入

统一数据格式

规范市场数据来源、字段和提取方式，降低每次重新整理的成本。

分析

多角色协同

评论分析、市场聚类、机会识别与质量审查分工完成，过程可追溯。

判断

Human in the Loop

在机会假设、方向选择和最终 Brief 前保留人的确认、修改和否决，不让模型越权。

沉淀

版本与决策记录

保存分析过程与方案变化，使后续同类项目可以复盘和复用。

Nextly 不是无人自动决策平台。AI 用于结构化信息、数据整理、分析、补充思路、候选方案和质量审查；但最终产品方向必须由人判断、确认、修改或拒绝。

AI RELIABILITY

AI 很强，但并不天然可靠。

01 / HALLUCINATION · 幻觉

风险：模型可能生成输入数据并不真正支持的结论。

机制：分析结果尽量保留数据依据；关键结论必须人工确认；AI 结果不能直接变成最终产品决策。

02 / MEMORY & DRIFT · 记忆与方向漂移

风险：长对话和复杂项目中，模型可能逐渐偏离最初项目目标、判断标准、输出格式和已确认方向。

机制：把项目原则、分析框架、输出规范和已确认判断沉淀为可复用 Skill，在关键阶段重新提供上下文，减少方向漂移。

03 / HUMAN AUTHORITY · 人的最终判断权

风险：模型容易把「分析建议」逐渐表达成「产品决定」。

机制：所有关键步骤都保持 Human in the Loop。AI 可以生成、归纳、分析、发散、审查，但最终产品方向必须由人判断、确认、修改或拒绝。

真正需要设计的不只是 Prompt，而是 AI 在业务中拥有怎样的权限。

MEASUREMENT NOTE
该结果来自对真实日常新品调研流程的经验拆解与个人工作流试运行。原流程包含：数据获取、评论下载、AI 分析、人工筛选、表格整理、PRD、头脑风暴、多轮修改和评审准备。Nextly 主要压缩重复数据整理、不同工具之间的信息转换、分析格式整理、PRD / Brief 前期准备和方案信息沉淀，最终仍保留人工关键决策。

BEFORE（原流程）：数据获取与整理 → 评论分析 → 人工筛选 → 表格重组 → PRD / Brief → 头脑风暴 → 修改与评审准备
AFTER（Nextly 后）：重复整理与格式转换明显压缩 → AI 辅助分析与初稿 → 人工判断 / 审核 / 方向决策保留

REFLECTION / 项目认识

真正有价值的不是“用了几个 Agent”，而是能否理解业务、定义清晰的输入输出，并知道哪些判断必须留给人。
